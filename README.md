# OkieMookie

Landing page for OkieMookie — BandLab production lessons, K-pop photocards & albums, and a growing collector community.

## Pages
- `index.html` — main landing page (hero, about, lessons, shop, community)
- `albums.html` — album listings
- `photocards.html` — photocard listings
- `book.html` — lesson booking page

## Structure
- `css/style.css` — all site styles
- `js/main.js` — nav, scroll reveals, hero video/audio, playlist crossfade
- `assets/` — images, video, and audio used by the site

No build step — plain HTML/CSS/JS, deployed as a static site.
